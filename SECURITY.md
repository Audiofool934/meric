# Security Policy

Meric is research software and is not a hardened production service.
We nevertheless take credible security reports seriously.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential.
Use GitHub private vulnerability reporting from the repository's Security tab.

Include the affected commit and files, reproduction steps, required preconditions, and expected impact when possible.

## Supported versions

Security fixes are applied to the current `main` branch.
Older snapshots and tags are not maintained separately.
